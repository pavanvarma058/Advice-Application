# Advice Application

A simple and interactive **Advice Application** built using **React** that fetches and displays random advice to users.  
This project helped me practice working with **React components, state, events, and API integration**.

## Features

- Get random advice with a single click
- Simple and clean user interface
- Built with reusable React components
- Uses API data to display dynamic content
- Beginner-friendly React project

## Tech Stack

- React
- JavaScript
- HTML
- CSS

## How It Works

The application fetches a piece of advice from an API and displays it on the screen.  
When the user clicks the button, a new advice message is generated and shown instantly.

## Learning Outcomes

Through this project, I practiced:

- Creating and managing React components
- Using `useState`
- Handling button click events
- Fetching data from an API
- Updating the UI dynamically
